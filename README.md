# hxwl-09 洁净室超限处置台

半导体洁净室采样留档与超限异常闭环处置的静态页面（React + Vite + TypeScript）。
针对“值班员改回合理读数盖掉异常痕迹、复测过程和标准查不到”的问题，系统只允许追加、不允许改写历史。

## 处置规则

- **采样留档**：每次采样记录房间、洁净等级、≥0.5μm / ≥5.0μm 粒子数、静压差、班次、采样人、现场说明。
- **同房间续单**：同一房间存在未结异常单时，新采样自动作为“复测”续到该单，不另开新单；异常关闭后再超限才会建新单。
- **粒子判定**：按等级套用 ISO 14644-1:2015 上限（ISO 5/6/7/8，两个粒径），任一粒径超限即粒子不合格。
- **压差判定**：相邻房间静压差 **15–25Pa（含边界）** 才算稳定。
- **关闭条件**（四项同时满足，关闭按钮才放行）：
  1. 至少一次复测；
  2. 最新复测粒子数回到等级上限内；
  3. 最新复测压差回到 15–25Pa（粒子与压差须在同一次复测同时恢复）；
  4. 处置人与复核人均签名且不是同一人。
- **关闭封存**：关闭后原始超限值、全部复测、处置记录、处置人/复核人保留可见，单据只读，不可再追加或修改。

## 防篡改

存档是 **只追加事件日志 + 哈希链（cyrb53）**：每条事件指纹包含前一条指纹与当时的判定标准快照。
系统不提供编辑/删除已提交采样的入口；直接改动 localStorage 历史数据会在“哈希链完整”校验处报出断裂位置。
支持导出 JSON（含完整性校验结果）。

## 四层分离维护

| 层 | 文件 | 职责 |
| --- | --- | --- |
| 资料 | `src/catalog.ts` | 房间台账（编号/名称/默认等级）、班次、人员名册 |
| 判定 | `src/rules.ts` | 等级粒子上限、压差稳定区间、采样判定、异常关闭条件（纯函数） |
| 本机存档 | `src/archive.ts` | 只追加事件、哈希链、重放派生台账/异常单、localStorage 持久化、导出、演示数据 |
| 界面 | `src/styles.css`、`src/App.tsx` | 录入、异常单处置、台账展示，不内嵌任何判定逻辑 |

调整标准（如换用其他级别限值）只改 `rules.ts`；改房间/人员只改 `catalog.ts`；历史记录保留判定时的标准版本快照。

## 本地运行

```bash
npm install
npm run dev      # http://localhost:5109
npm run build    # 产出 dist/ 静态包
```

页面底部“存档维护”可载入演示数据（含 2 张未结单：1 张复测已恢复待双签、1 张等待复测；1 张已关闭封存单），也可导出 JSON 或清空本机存档。
