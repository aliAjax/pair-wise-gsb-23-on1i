# hxwl-09 洁净室超限处置台

洁净室超限处置台：采样留档、超限开单、复测续单、双人签认关闭，原值全程留痕。

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5109

## 分层结构（资料 / 判定 / 存档 / 界面分开维护）

- `src/data.ts` —— 资料：房间、洁净等级、粒子上限（按 ISO 14644-1 等级）、压差稳定区间（15–25 Pa）、班次与类型定义
- `src/rules.ts` —— 判定：超限判定、未结异常单查找、关闭条件校验（纯函数）
- `src/storage.ts` —— 本机存档：localStorage 读写、演示数据、清空
- `src/App.tsx` —— 界面：采样录入、未结异常单、已关闭档案、采样留档表

## 业务规则

- 采样按房间、等级、粒子数、压差、班次留档，录入后不可修改
- 粒子上限按等级判定；压差在 15–25 Pa 才算稳定
- 超限自动开立异常单并锁定原值；同房间有未结异常时，新采样只续到那张单上
- 关闭条件：最近复测粒子与压差两项均恢复，且处置人与复核人不同
- 关闭后原值、复测记录与签认人保留，只读存档
- 支持导出存档 JSON 与清空本机存档
